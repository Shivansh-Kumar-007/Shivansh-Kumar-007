# Pixel developer room

Original artwork created with the built-in image generation tool for this profile. The character is a stylized developer, not a portrait likeness.

## Prompt

Create an animation sprite sheet for a GitHub profile banner: one column of four equal, edge-to-edge panoramic frames, no gutters or labels. Repeat the same cozy pixel developer room in every frame, changing only rainfall and monitor cursor details for subtle animation. Authentic 16-bit game art with midnight navy walls, warm amber desk lighting, mint code on two monitors, a dark-haired developer viewed from behind, houseplants, books, a coffee mug, and a large window overlooking a rainy blue city. Cinematic 3:1 composition, clear silhouettes, restrained teal accents, no logos or written text.

## Production

The generated four-frame sheet was separated and encoded with FFmpeg into a four-frame GIF at 4 frames per second, looping indefinitely. The still PNG is its first frame. This is a short illustrated loop; small changes in generated details between frames are part of the result. No third-party image hosts or runtime services are required.

## Profile interface, version 2

The player header, navigation buttons, experience panel, and save-point footer are original code-native SVG assets. They use local vector shapes, system monospace fonts, and declarative SVG animation. No JavaScript, remote image services, external fonts, or profile-stat services are used. The generated room artwork remains the same as version 1.
